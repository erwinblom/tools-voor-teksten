# App-icoon

Document als functiesymbool binnen de vaste FMT-iconenfamilie. Het target (vier balken en rode stip), de witte tegel en hun geometrie zijn ongewijzigd overgenomen uit de canonieke fmt-werkplaats.svg. Het nieuwe document is het functiesymbool van Tools voor Teksten.

app-icon.svg is de versiebeheerbare bron. PNG/ICNS zijn hiervan afgeleid, zonder fontafhankelijkheid. Merkvoorwaarden staan in MERKVOORWAARDEN.md. Uitgevoerde documenten krijgen geen verplicht logo.
